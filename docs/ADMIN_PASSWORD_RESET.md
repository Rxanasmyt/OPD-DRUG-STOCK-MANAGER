# ให้ Admin รีเซ็ตรหัสผ่านผู้ใช้ (กรณีลืมรหัส)

Firebase เปลี่ยนรหัสผ่านของ "คนอื่น" ได้เฉพาะจากฝั่งเซิร์ฟเวอร์ (Admin SDK) แอพจึงเรียก Cloud Function
`adminResetPassword` (โฟลเดอร์ `functions/`) — ปุ่ม **รีเซ็ตรหัสผ่าน** ในหน้า Admin จะใช้งานได้หลัง deploy ตามขั้นตอนนี้

> ก่อน deploy ปุ่มจะขึ้นข้อความว่า "ฟังก์ชันรีเซ็ตรหัสผ่านยังไม่ได้เปิดใช้งาน" — ไม่กระทบส่วนอื่นของแอพ

## สิ่งที่ต้องมี (ครั้งเดียว)
1. อัปเกรดโปรเจกต์ `opd-drug-stock` เป็นแผน **Blaze** (จ่ายตามใช้จริง — การรีเซ็ตรหัสผ่านไม่กี่ครั้งต่อเดือนอยู่ในโควตาฟรี
   แต่ Firebase บังคับให้ผูกบัตรเพื่อใช้ Cloud Functions) ที่ Firebase Console → Usage and billing
   *แนะนำให้ตั้ง Budget alert (เช่น 100 บาท) ไว้ด้วย*
2. เครื่องที่ติดตั้ง Node 20+ และ Firebase CLI: `npm i -g firebase-tools` แล้ว `firebase login`

## Deploy
```bash
cd functions && npm install && cd ..
firebase deploy --only functions --project opd-drug-stock
```
(เวิร์กโฟลว์ deploy อัตโนมัติของ repo นี้ deploy เฉพาะ Hosting + Firestore rules จึงไม่แตะ Functions — ต้องรันคำสั่งนี้เองเมื่อแก้โค้ดใน `functions/`)

## วิธีใช้งาน
หน้า Admin → แท็บ ผู้ใช้งาน → เลือกผู้ใช้ → **รีเซ็ตรหัสผ่าน** → ระบบสุ่มรหัสชั่วคราวให้ (แสดงครั้งเดียว กดคัดลอกแล้วแจ้งผู้ใช้)
ผู้ใช้เข้าสู่ระบบด้วยรหัสชั่วคราว แล้วระบบบังคับให้ตั้งรหัสผ่านใหม่ก่อนใช้งานต่อ

## ความปลอดภัย
- ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์: ผู้เรียกต้องเป็น Admin ที่ `active` เท่านั้น (ไม่เชื่อสิ่งที่ไคลเอนต์ส่งมา)
- รีเซ็ตตัวเองไม่ได้ (ใช้ "เปลี่ยนรหัสผ่านของฉัน")
- รหัสชั่วคราวสุ่มบนเซิร์ฟเวอร์ ไม่ถูกเก็บใน Firestore/log; session เดิมของผู้ใช้ถูกยกเลิก
- ทุกครั้งบันทึก audit log (`user_password_reset`) ว่าใครรีเซ็ตให้ใคร (ไม่มีรหัสผ่านในบันทึก)
