# ให้ Admin รีเซ็ตรหัสผ่านผู้ใช้ (กรณีลืมรหัส)

Firebase เปลี่ยนรหัสผ่านของ "คนอื่น" ได้เฉพาะจากฝั่งเซิร์ฟเวอร์ (Admin SDK) โปรเจกต์นี้ไม่ใช้ Cloud Functions/แผน Blaze
จึงทำเป็น **GitHub Action ที่สั่งรันเอง** (`.github/workflows/reset-user-password.yml` → `scripts/reset-user-password.mjs`)
ใช้ secret `FIREBASE_SERVICE_ACCOUNT_KEY` ตัวเดียวกับสคริปต์อื่นของ repo (ไม่ต้องตั้งค่าเพิ่มถ้ามีอยู่แล้ว)

## วิธีใช้
1. แอพ → หน้า Admin → ผู้ใช้ที่ลืมรหัส → **🔑 รีเซ็ตรหัสผ่าน (ลืมรหัส)** → กด **เปิดหน้ารีเซ็ต (GitHub)**
   (หรือเข้า GitHub → แท็บ Actions → "Reset User Password" เอง) — ต้องล็อกอิน GitHub ที่มีสิทธิ์เขียนใน repo
2. กด **Run workflow** → กรอก **username** (ปุ่ม "คัดลอก username" ในแอพช่วยได้) → Run
3. รอ ~1 นาที เปิดการรันที่เสร็จ → หน้า **Summary** มีรหัสผ่านชั่วคราว → แจ้งผู้ใช้โดยตรง
4. ผู้ใช้เข้าสู่ระบบด้วยรหัสชั่วคราว → แอพบังคับให้ **ตั้งรหัสผ่านใหม่ของตัวเอง** ก่อนใช้งาน
5. จดรหัสแล้ว **ลบการรันนั้น** (⋯ → Delete workflow run) เพื่อไม่ให้รหัสค้างในหน้า GitHub

## สิ่งที่สคริปต์ทำ
- หา username ใน `users/` (ไม่พบ = ไม่เปลี่ยนอะไร)
- ตั้งรหัสสุ่ม 12 ตัว (ไม่มีตัวที่สับสน 0/O/1/l/I), ยกเลิก session เดิมของผู้ใช้
- ตั้ง `users/{uid}.mustChangePassword = true` (กฎ `firestore.rules` ให้เจ้าของบัญชีล้างเป็น false ได้หลังตั้งรหัสใหม่)
- บันทึก audit `user_password_reset` ว่าใครสั่ง (GitHub username) ให้ใคร — ไม่มีรหัสผ่านในบันทึก
- เขียนรหัสชั่วคราวลง **Job summary เท่านั้น** ไม่ลง log ปกติ

## ข้อควรรู้ด้านความปลอดภัย
- ใครก็ตามที่เปิดดูผลการรัน (Actions) ของ repo ได้ จะเห็นรหัสชั่วคราวใน Summary — ถ้า repo เป็น public ทุกคนเห็นได้
  จึงควรให้ repo เป็น private และลบการรันทันทีหลังจดรหัส (รหัสใช้ได้จนกว่าผู้ใช้จะตั้งรหัสใหม่)
- การสั่งรันต้องมีสิทธิ์เขียนใน repo (เจ้าของ/ผู้ร่วมงาน) ไม่ใช่ Admin ของแอพทุกคน — ถ้า Admin ของแอพไม่มีบัญชี GitHub ต้องให้เจ้าของ repo เป็นคนสั่งแทน
- ยังไม่ได้ทดสอบกับ Firebase จริง (ทดสอบด้วย mock) — ครั้งแรกให้ลองกับบัญชีทดสอบก่อน
